# Design System

## Visual Theme

Minimal editorial portfolio using a 640px centered column, large quiet margins, Zahirul's real product and photography imagery, soft elevated surfaces, and sparse utility controls fixed near the top corners.

## Color Palette

- Light page: `#ffffff`
- Light ink / copy: `#171717` / `#404040`
- Dark page: `#0a0a0a`
- Dark ink / copy: `#f5f5f5` / `#d4d4d4`
- Elevated dark surface: `#171717`

## Typography

- Sans: Geist Variable, 100-900
- Mono: Geist Mono Variable, 100-900
- Home heading: 26px / 1.3 / 560
- Reading copy: 18px / 1.6 on desktop, 16px minimum on small screens
- Section heading: 24px / 1.3 / 560

## Layout

- Reading column: 640px plus responsive gutters
- Header control envelope: 860px
- Desktop hero top offset: `17vh`, clamped to 104-164px
- Work reel slide: 640px maximum with 8px side inset and 4:3 media
- Mobile gutter: 20px; work media retains a full-width horizontal reel
- Past-work index: full-width rows with year, type, project, and a far-right arrow; columns compress proportionally on mobile

## Components

Fixed site controls, circular-reveal navigation, animated light/dark toggle, muted social-icon links, reusable draggable visual reels, a hover-highlighted project index, a generated Codex session activity grid, one flagship SesiFoto card inside the Infyra chapter, split personal-story sections, conversation rows, playground cards, infinite draggable gallery, and configurable smiley desk pet.

## Motion

Short blur/translate route entrances, circular menu reveal, tactile hover elevation, horizontal wheel/drag work movement, draggable gallery plane, responsive pet states, and complete reduced-motion fallbacks.
